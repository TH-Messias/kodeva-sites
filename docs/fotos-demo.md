# Fotos das demonstrações (para gerar com IA de imagem)

Estas fotos são só para as demonstrações da vitrine, onde já aparece o aviso "fotos ilustrativas". Nunca use foto gerada por IA no site de uma cliente como se fosse do negócio dela.

Como usar: gere no ChatGPT (imagem), Gemini ou Midjourney, salve com o nome indicado em `exemplos/<modelo>/` e rode `npm run demos`. Peça sempre **sem texto, sem logotipo e sem marca de carro** na imagem.

Estilo comum a todas: `photorealistic, natural light, shot on 35mm, shallow depth of field, no text, no logos, no watermark, Brazilian small business`.
