# Lumea Clínica

Landing page de clínica de medicina estética. Vite + React + TypeScript + Tailwind v4 + Motion + Phosphor Icons.

```bash
npm install
npm run dev
```

Conteúdo editável em `src/data.ts` (WhatsApp, tratamentos, equipe, galeria). As imagens atuais são placeholders (picsum / randomuser) e devem ser trocadas por fotos reais da clínica e da equipe.
